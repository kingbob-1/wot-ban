# 使用说明（坦克世界封号案底查询工具 v0.1.0）

> 适用于 Windows 10 / 11、坦克世界 360 国服。
> 本工具把官方公开的历史封禁名单建成本地档案库，并把本地录像里的参战玩家与名单逐局比对。
> **历史封禁记录 ≠ 当前违规 / 当前开挂**；数据非官方口径，**禁止用于挂人、骚扰或任何处罚依据**。

---

## 1. 它能做什么、不能做什么

**能做**

- 查某个玩家**历史上是否被 360 官方封禁过**：几次、最近一次日期、原因、时长、来源批次与公告链接；
- 把一局录像里的 30 名玩家整体比对：谁上过名单一目了然（黄标 1 次 / 红标 ≥2 次）；
- 完整录像按账号 ID 精确匹配，partial（未打完）录像按昵称匹配并明确标注；
- 按需查看当局战绩（仅最近 180 天完整对局）与玩家综合战绩（点查、缓存）；
- 本地维护名单库：启动自动检查更新、手动更新、清空/重建、查看数据状态。

**不能做**

- 不判断玩家**当前**是否开挂、不提供任何「挂狗鉴定」结论；
- 不提供游戏内 overlay、不注入游戏、不需要启动游戏；
- 不导出名单数据、不提供在线查询服务、不转发名单；
- 不覆盖亚服/国际服（它们没有公开封禁名单）。

## 2. 安装与启动

### 2.1 便携包（推荐）

1. 从 [GitHub Releases](https://github.com/kingbob-1/wot-ban/releases) 下载 Windows 便携包（zip，约 250 MB）；
2. 解压到任意目录（**不要**解压到需要管理员权限的目录，如 `C:\Program Files`）；
3. 双击目录内的 **`run.bat`**。

便携包内已含 Python 3.12 与 PySide6，**无需另外安装 Python**。数据、日志、配置都生成在解压目录内，删除目录即彻底卸载。

### 2.2 源码运行（开发者）

```bat
python -m pip install PySide6
python main.py
```

本机自用（工作区共享运行时）：双击项目内 `run.bat` 即可；它自动使用 `..\runtime\python.exe`，优先以 `pythonw.exe` 无控制台启动。详细命令见 [README](../README.md)。

### 2.3 首次启动配置（源码运行 / 便携包通用）

程序内置的默认路径是开发机路径（录像目录 `X:\World_of_Tanks_CN\replays`、名单归档 `<工作区>\research\wot-ban\archive`）。

> **便携包 / 新环境用户：请在首次启动前先创建下面的 `config.local.json`**。至少配置 `replay_dir`（录像目录）与 `archive_dir`（名单归档目录）；否则程序可能找不到录像，或名单下载无处落盘导致首次抓取失败。本机自用（开发工作区）沿用默认值即可，不必修改。

在程序目录（`main.py` 所在目录）下新建 `config.local.json`：

```json
{
  "replay_dir": "D:\\World_of_Tanks_CN\\replays",
  "archive_dir": "archive"
}
```

- `replay_dir`：你的坦克世界录像目录（里面是 `.wotreplay` 文件）；
- `archive_dir`：名单归档/下载落盘目录。便携包用户建议写相对路径 `"archive"`（即程序目录下的 `archive\`），不要留空；
- 该文件已被 `.gitignore` 排除，不会被提交、不会上传；改完重启程序生效。
- 也可以在界面「手动选择…」临时打开单个录像文件，不必配置 `replay_dir`。

## 3. 首次启动与名单库

第一次启动时名单库是空的，程序会：

1. 自动创建数据库 `data\wotban.db` 与日志目录 `log\`；
2. 自动触发一次名单检查/抓取（**约 5–6 分钟**，取决于网络；官方接口低频只读，≥2 秒/请求）；
3. 抓取完成后顶栏显示「数据更新 / 名单规模 / wgid 覆盖 / 缺失批次 / 上次检查」。

> 公开版首次运行自动抓取的是官方 **CSV 系列名单（96 期，2021-08-16 起，约 25.6 万条）**。2020-08 ~ 2021-08 的 18 期 xlsx 是官方公告附件形式，不在自动抓取范围内（本机开发者档案额外包含这 18 期，故完整口径为 322,941 条源记录 / 322,806 条去重入库）。

若首次抓取失败：看界面提示与 `log\` 下的日志；确认能正常访问 `profile.wg.360.cn`（需要时可配置系统代理后重试），稍后点「更新名单」重试。**更新期间可随时取消。**

## 5. 更新名单

- **自动**：每次启动检查一次；程序运行期间每 **6 小时**检查一次；界面显示上次检查时间。
- **手动**：点「更新名单」立即检查（`force` 模式，忽略 6 小时间隔）。
- **只读**：全部为官方公开接口的只读 GET（≥2 秒/请求、无并发）；不登录、不绕过风控。
- **风控中止**：遇到 403 / 412 / 429 / 503 会立即中止并给出中文提示，**不会重试绕过**，也不会更新「上次检查时间」。
- **漏期说明**：程序不创建 Windows 计划任务。程序未运行的期间官方若发布了新一期，**该期约 100 个账号 ID（wgid）会永久错过**（官方只提供最新一期前 100 条 ID，无法回补）；历史封禁记录本身仍会补抓，只是当期的账号 ID 缺失。
- **新增批次**：先存档最新一期 JSON 的 `wgid` → 再按日期间隔下载缺失期 CSV → 入库去重，重复运行幂等。

## 6. 选择与扫描录像

| 入口 | 行为 | 适用场景 |
|---|---|---|
| 最新完整录像 | 定位最近一局打完的完整录像并加载 | 刚打完一局想立刻看 |
| 最近 7 天 | 扫描最近 7 天的录像，可下拉切换 | 日常复盘 |
| 全部录像 | 扫描整个录像目录（首次较慢，之后走增量缓存） | 大范围检索 |
| 手动选择… | 直接打开单个 `.wotreplay` 文件 | 录像目录不固定/只想看某一局 |

- 录像目录默认 `X:\World_of_Tanks_CN\replays`，不同请按 §2.3 配置 `config.local.json`；
- 扫描时显示进度，可随时「取消」（后台线程执行，不卡界面）；
- 损坏/不完整文件会被跳过，不中断整体扫描；
- **完整录像**（打完的局）可解析出全部玩家账号 ID；**partial 录像**（未打完，约占 56%）只有昵称/军团/坦克信息，界面标注「partial」并按昵称匹配；
- 同一录像重复扫描命中增量缓存，速度很快。

## 7. 看查询结果

结果表列：阵营 / 昵称 / 账号 ID / 军团缩写 / 封禁次数 / 最近封禁日期 / 原因 / 时长 / 匹配方式 / 本局战力 / 伤害 / 击杀 / 经验 / 命中率。

- **黄底 = 历史封禁 1 次；红底 = 2 次及以上**；
- **匹配方式**：
  - `ID 确认`：完整录像的账号 ID 与名单 `wgid` 精确一致（最可靠）；
  - `昵称匹配`：该记录无账号 ID（历史批次），按同一昵称视为同一人；
  - `仅昵称匹配`：partial 录像没有账号 ID，只能按昵称匹配（计入黄/红，但存在同名不同人的可能）；
- **排序**：默认按封禁次数降序、同次数按最近封禁日期降序；点击表头可切换排序；
- **筛选**：「只看命中」只显示上过名单的玩家；「仅看 ID 命中」只显示 ID 精确匹配的行；「标色」可按黄/红筛选；
- 底部汇总显示「本局 N 人 · 命中 M 人（ID 确认 / 昵称匹配 / 黄标 / 红标）」。

---

## 8. 看玩家明细

在结果表点击任意一行，右侧「明细」面板显示：

- 玩家昵称、匹配方式、封禁次数（黄/红徽标）、账号 ID（partial 显示「—（partial 录像无 ID）」）、军团、本局坦克；
- **封禁记录表**：每条记录的批次日期、原因、时长、累计次数、来源类型（CSV / xlsx / JSON），以及来源批次 / 公告链接（可点击查看、可复制）/ 抓取时间——可核对官方原始出处；
- 未命中名单时显示「未命中任何历史封禁记录」。

---

## 9. 当局战绩（按需加载）

- 打开**完整录像**且对局时间在**最近 180 天**内时，自动按需请求一次当局战绩（本局战力、伤害、击杀、经验、命中率等），可看到本局全部 30 人的战绩；
- **partial 录像**（无 `arena_id`）与**超过 180 天的对局**：**不发起任何请求**，界面明确提示「该局超出战绩接口 180 天范围 / partial 不可用」；
- 战绩来自偶游盒子 `battledetail`，**非官方数据、仅供参考**；「本局战力 ≠ 伤害」；
- 同一局重复打开走本地缓存（0 请求）；请求失败会降级提示，不阻塞主表。

---

## 10. 综合战绩（点查）

- 仅当点击明细区的「点查综合战绩」时才请求，不点不请求；
- 数据来自偶游盒子 `index` 页面，口径为「**最近 1500 场标准局**」，非官方、仅供参考；
- 限流 ≥2 秒/请求，本地缓存 12–24 小时；失败或限流时给出提示，不影响封禁查询。

## 11. 数据状态与维护

点顶栏「数据状态」打开「名单库状态」窗口：

| 字段 | 含义 |
|---|---|
| 批次数 / 库内条数 / 官方源（物理行） | 名单库规模（本机完整档案：114 批 / 322,806 条去重入库 / 322,941 条官方源物理行） |
| 覆盖区间 / 最新批次 | 最早 ~ 最新批次日（本机完整档案：2020-08-14 ~ 2026-11-06） |
| `wgid` 覆盖 | 有多少期、多少条记录带账号 ID（历史批次没有，属官方数据限制） |
| 缺失批次 | 应为「无」；有缺失时可点「更新名单」补齐 |
| 上次检查 / 上次更新 | 最近一次检查官方接口 / 最近一次实际写入新数据的时间 |
| 录像索引 | 已扫描并缓存的录像数量 |
| 批次表 | 每期批次日、来源类型（CSV / xlsx / JSON）、记录数、带 `wgid` 记录数 |

窗口按钮：

- **打开数据目录**：`data\`（数据库所在）；
- **打开日志目录**：`log\`（排查问题用）；
- **清空名单库**：**二次确认**后清空 `bans` 表（录像索引保留）。清空后查询不到任何封禁记录，需要重新导入：本机有归档可点「重建名单库」；公开版请点「更新名单」从官方接口重新抓取（约 5–6 分钟）；
- **重建名单库**：从**本地名单归档**（`archive_dir`）重新导入 96 期 CSV + 18 期 xlsx（仅当本机有归档时可用；没有归档会报错提示，改用「更新名单」）。

## 12. 数据、配置与日志位置

| 内容 | 位置 | 是否可删 | 说明 |
|---|---|---|---|
| 数据库 | `data\wotban.db` | 可删（下次重建） | 名单库 + 录像索引 + 缓存 |
| 日志 | `log\*.txt` | 可删 | 按启动时间分文件；反馈问题时附上 |
| 本机配置 | `config.local.json` | 可删（恢复默认） | 录像目录、归档目录等本机路径；不入库不上传 |
| 名单归档（本机） | `archive_dir` 指向的目录 | 可删 | 抓取缓存/归档；「重建名单库」依赖它 |
| 程序配置默认值 | `src\config.py` | 不建议改 | 路径/接口/限流阈值集中定义 |

## 13. 常见问题排查（FAQ）

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 双击 `run.bat` 一闪而过 | 源码版 `run.bat` 依赖工作区 `..\runtime\python.exe`；公开用户用错入口 | 便携包用包内 `run.bat`；源码用户改用 `python main.py` |
| 提示缺少 PySide6 | 源码环境未安装依赖 | `python -m pip install PySide6` |
| 首次更新很慢或失败 | 网络不通/代理问题/官方接口变更/被风控 | 检查网络与代理；稍后重试；看 `log\` 中文错误；遇到 429/403 停止重试 |
| 扫描不到录像 | 录像目录不存在或没有 `.wotreplay` | 按 §2.3 配置正确 `replay_dir`；确认游戏内开启「保存录像」；或「手动选择…」 |
| 提示「该局超出战绩接口 180 天范围」 | 对局超过 180 天 | 正常提示，仅封禁信息可查；不发起战绩请求 |
| 提示 partial / 仅昵称匹配 | 录像未打完，没有玩家账号 ID | 正常现象；昵称匹配计入黄/红，注意同名不同人可能 |
| 战绩一直「不可用」 | 超期局、partial 局、盒子限流或网络失败 | 属正常降级；主表封禁查询不受影响 |
| 名单库为空 | 首次未抓取/被清空 | 点「更新名单」重新抓取（本机有归档可「重建名单库」） |
| 数据状态显示「缺失批次」 | 某期未导入成功 | 点「更新名单」补齐；仍失败看日志 |
| 界面按钮点了没反应/卡住 | 上一次后台任务未结束（更新/扫描/点查进行中） | 等进度条完成或点「取消」；仍异常请重启程序并附日志 |
| 杀毒软件报毒 | 便携包内含 Python 解释器，个别杀软敏感 | 源码 + 解释器方式分发，不含 exe；可加入信任或自行源码运行 |
| 想彻底卸载 | — | 关闭程序后直接删除整个程序目录（数据/日志/配置都在目录内）；源码方式另删 `data\`、`log\`、`config.local.json` |

反馈问题时请提供：`log\` 下对应日志、界面提示原文、Windows 版本、是否便携包；**请勿附带包含个人信息/账号信息的截图**。
